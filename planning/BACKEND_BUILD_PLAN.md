## 0. How to use this document

### 0.1 Anti-hallucination rules (read FIRST, before any phase)

These rules prevent the most common mistakes. Internalize them.

1. **Schema is ground truth.** Every event name, payload field, HTTP endpoint, and DB column lives in `almanac/planning/schemas/`. NEVER invent a name. If it's not in almanac, it's not in the system.
2. **Money is `BIGINT IDR`, no decimals.** `10000` IDR = `10000`, not `100.00`. `BIGINT NOT NULL CHECK (amount > 0)`. Never use `float` or `numeric` for money.
3. **Append-only ledger.** `ledger_entries` rows are never UPDATEd or DELETEd. Corrections are reversal entries with `reversal_of` set.
4. **Idempotency keys are mandatory.** Every webhook, every external write. Format: `provider_name:event_id`. Stored in `idempotency` table with UNIQUE constraint.
5. **Tokens are opaque with prefix.** `sk_<base64url>` for session, `ok_<base64url>` for overlay. Stored in DB as bcrypt hash. Never log the raw token.
6. **Sequence numbers are per-streamer monotonic.** `seq` increments by 1 per fanout. Starts at 1 on gateway boot. Wraps at `2^53 - 1`.
7. **Concurrency: per-streamer isolation.** WebSocket hub keyed by `streamer_id`. Lock granularity = per hub, not global.
8. **All events go through NATS JetStream.** No service-to-service HTTP for async events. Use NATS subject naming `<domain>.<entity>.<verb>.<version>`.
9. **Standard error format from 00-frozen-contracts §6.** Every non-2xx HTTP response: `{"error": {"code", "message", "request_id", "details?"}}`. Never invent error codes.
10. **Time is RFC 3339 UTC, ms precision.** Stored as `TIMESTAMPTZ` in DB. Never use unix timestamps in JSON.
11. **UUIDs are v4 lowercase with dashes.** 36 chars. Generated by `gen_random_uuid()` in DB or `crypto/rand` in Go. Never use `auto_increment` for externally-visible IDs.
12. **No silent failures.** Every error path logs at WARN or ERROR with `request_id` and `streamer_id` if available.

```

```

**Why polyrepo** (not monorepo):
1. Each service has independent version, CI pipeline, deploy cadence.
2. Smaller, focused repos reduce clone time and IDE noise.
3. Schema changes (in almanac) are the integration contract — code-level coupling is minimized.
4.Friend works independently on `inflora-ws-gateway` without waiting forMarvel's PRs.

**Cross-service types come from `inflora-shared`** (imported by all 5 services as `github.com/frederickmarvel/inflora-shared`). **No service imports another service.**

For complete service-to-service wiring (event topics, gRPC matrix, HTTP matrix, DB ownership per table), see **`WIRE_GUIDE.md`** §1-6. **Never invent a connection not in WIRE_GUIDE.**

## 2. Cross-cutting concerns (apply to every phase)

### 2.1 Configuration

Every service reads env vars. Implementation: `pkg/config` (Phase 1).

Required env vars per service:
```
SERVICE_NAME=<service>
HTTP_ADDR=:8080
DB_DRIVER=postgres
DB_DSN=postgres://user:pass@host:5432/db?sslmode=disable
NATS_URL=nats://localhost:4222
LOG_LEVEL=info
LOG_FORMAT=json
OTEL_EXPORTER_OTLP_ENDPOINT=localhost:4317
```

Read once at startup. Hot-reload NOT in MVP. Restart on config change.

### 2.2 Logging

Format: JSON per `00-frozen-contracts.md §10`. Use `zap` or `zerolog`.

Required:
```go
log.Info("donation settled",
    zap.String("request_id", reqID),
    zap.String("streamer_id", streamerID),
    zap.String("donation_id", donationID),
    zap.Int64("amount_idr", amount),
)
```

Never log:
- Raw tokens (use `last4` only)
- Raw passwords
- Full bank account numbers (use `last4` only)
- Full credit card numbers (NEVER)

### 2.3 Tracing

Use OpenTelemetry. Every request: `trace_id` propagates through headers → logs → events.

Implementation: `pkg/observability/tracer.go` (Phase 1).

### 2.4 Metrics

Prometheus. Required metrics per service:

```
# HTTP
http_requests_total{service, method, path, status}
http_request_duration_seconds{service, method, path}  # histogram

# DB
db_connections_active{service, database}
db_query_duration_seconds{service, query_type}  # histogram

# Events
events_published_total{service, topic}
events_consumed_total{service, topic, consumer_group}

# Service-specific (saruman)
ledger_balance_idr_total{account_type}  # gauge
donations_settled_total{service}  # counter

# Service-specific (ws-gateway)
ws_connections_active{service, streamer_id}
ws_reconnect_attempts_total{service, streamer_id}
```

Expose at `GET /metrics`. Internal-only.

### 2.5 Error handling

Standard error response per `00-frozen-contracts.md §6`:

```go
type Error struct {
    Code    string                 `json:"code"`
    Message string                 `json:"message"`
    RequestID string                `json:"request_id"`
    Details map[string]interface{} `json:"details,omitempty"`
}
```

Error codes (only use these — never invent):
- `VALIDATION_FAILED`, `INVALID_SIGNATURE`, `CAPTCHA_FAILED` (400)
- `INVALID_TOKEN`, `TOKEN_EXPIRED` (401)
- `STREAMER_INACTIVE`, `STREAMER_HOLD_ACTIVE` (403)
- `STREAMER_NOT_FOUND`, `BANK_ACCOUNT_NOT_FOUND`, `DONATION_NOT_FOUND` (404)
- `EMAIL_EXISTS`, `IDEMPOTENCY_CONFLICT` (409)
- `INSUFFICIENT_BALANCE`, `INSUFFICIENT_AMOUNT`, `BELOW_MIN_WITHDRAWAL`, `BATCH_HAS_HOLDS` (422)
- `RATE_LIMITED` (429)
- `PROVIDER_ERROR` (502)
- `INTERNAL`, `SERVICE_UNAVAILABLE` (500/503)

### 2.6 Middleware (every HTTP service)

Every HTTP server has:
1. `requestID` — generates `X-Request-Id` if missing, propagates to logs.
2. `tracing` — OpenTelemetry span per request.
3. `logging` — structured log per request with latency.
4. `metrics` — Prometheus counter + histogram per request.
5. `recovery` — panics return JSON 500, never leak stack to user.
6. `auth` — applies per-route, validates Bearer token, sets `streamer_id` in context.
7. `cors` — allow `https://app.inflora.app`, `https://ingest.inflora.app` (origins).
8. `ratelimit` — per IP, per route (uses Redis or in-memory token bucket at MVP).

### 5.4 Code structure

```go
// services/saruman/cmd/migrate/main.go
package main

import (
    "flag"
    "log"
    "github.com/inflora/backend/services/saruman/migrations"
    "github.com/inflora/backend/pkg/db"
)

func main() {
    direction := flag.String("dir", "up", "up or down")
    target := flag.String("target", "", "specific migration (default: all)")
    flag.Parse()

    cfg, err := config.Load("saruman")
    if err != nil { log.Fatal(err) }

    db, err := db.NewPostgres(context.Background(), cfg.DB_DSN, 50)
    if err != nil { log.Fatal(err) }

    if err := migrations.Run(db, *direction, *target); err != nil {
        log.Fatal(err)
    }
    log.Printf("migrations %s complete", *direction)
}
```

### 5.5 Migration strategy

Use `golang-migrate/migrate` library OR hand-rolled embed.FS iteration. Decision pending — pick ONE, document the choice.

**Hand-rolled approach** (recommended for control):
1. Create `schema_migrations` table: `(version BIGINT PRIMARY KEY, applied_at TIMESTAMPTZ, name TEXT)`.
2. On `up`: read each `*.up.sql` in order, skip if version already applied, record after apply.
4. On `down`: find highest version, apply its `.down.sql`, decrement record.

**Lock**: `pg_advisory_lock(?)` at top of migration to prevent concurrent runs.

func (s *Service) SettleDonation(ctx context.Context, req SettleDonationRequest) (SettleDonationResponse, error) {
    donationID := req.DonationID

    // Check idempotency at saruman level
    // SELECT donations WHERE id=? AND status='INTENT_CREATED'
    donation, err := s.donations.GetByID(ctx, donationID)
    if err != nil { return SettleDonationResponse{}, ErrDonationNotFound }
    if donation.Status != INTENT_CREATED {
        // Already settled or failed — idempotent return
        return SettleDonationResponse{Status: donation.Status}, nil
    }

    // Compute fee
    platformFeeID := req.AmountIDR * platformFeeBPS / 10000
    netIDR := req.AmountIDR - platformFeeID

    // BEGIN TX (serializable)
    err = s.db.InTx(ctx, func(tx *sql.Tx) error {
        // 1. UPDATE donations
        _, err := tx.Exec(`
            UPDATE donations SET
              status = 'CHARGED',
              settlement_status = 'PENDING',
              amount_idr = ?,
              mdr_idr = ?,
              mdr_rate_bps = ?,
              gross_charged_idr = ?,
              platform_fee_idr = ?,
              net_idr = ?,
              provider_charge_id = ?,
              provider_name = ?,
              payment_method = ?,
              charged_at = NOW(),
              voice_url = ?,
              voice_duration_sec = ?,
              youtube_url = ?,
              youtube_start_sec = ?,
              youtube_end_sec = ?,
              display_duration_sec = ?
            WHERE id = ?`,
            // ... parameters ...
        )

        // 2. INSERT ledger_entries x 2 (or use pkg/ledger.DoubleEntry)
        err = s.ledger.DoubleEntry(ctx, tx, ledger.DoubleEntryParams{
            StreamerID: donation.StreamerID,
            CorrelationID: req.CorrelationID,
            DebitAccount: AccountDonorCash,
            CreditAccount: AccountStreamerPending,
            AmountIDR: netIDR,
            EntryType: ledger.EntryDonation_DEPOSIT,
            DonationID: &donationID,
            ExternalRef: req.ProviderChargeID,
        })
        // ... and second entry for platform fee ...

        // 3. UPDATE ledger_accounts.balance + version++ (handled by DoubleEntry)
        return nil
    })
    if err != nil { return SettleDonationResponse{}, err }

    // 4. Publish donation.charged.v1.<streamer_id>  -- post-commit, in transaction-outbox pattern
    s.events.Publish(ctx, "donation.charged.v1."+donation.StreamerID, envelope.Envelope{...})

    // 5. Trigger email receipt (fire-and-forget, async)
    if donation.DonorEmail != "" {
        go s.email.SendReceipt(ctx, donation)
    }

    return SettleDonationResponse{Status: "CHARGED"}, nil
}
```

// services/ws-gateway/internal/ws/hub.go
type Hub struct {
    StreamerID string
    Connections map[*Connection]struct{}
    Seq        atomic.Uint64   // monotonic per-streamer seq
    mu         sync.RWMutex
    log        *zap.Logger
}

func NewHub(streamerID string, log *zap.Logger) *Hub {
    return &Hub{
        StreamerID: streamerID,
        Connections: make(map[*Connection]struct{}),
        log: log,
    }
}

func (h *Hub) AddConnection(c *Connection) {
    h.mu.Lock()
    defer h.mu.Unlock()
    h.Connections[c] = struct{}{}
}

func (h *Hub) RemoveConnection(c *Connection) {
    h.mu.Lock()
    defer h.mu.Unlock()
    delete(h.Connections, c)
}

func (h *Hub) Broadcast(frame []byte) {
    h.mu.RLock()
    defer h.mu.RUnlock()
    for conn := range h.Connections {
        select {
        case conn.Send <- frame:
        default:
            // slow consumer — disconnect
            go conn.Close(1011, "slow consumer")
        }
    }
}

// services/ws-gateway/internal/ws/connection.go
type Connection struct {
    ws       *websocket.Conn
    Send     chan []byte
    StreamerID string
    LastSeq  uint64
    Hub      *Hub
    log      *zap.Logger
}

func (c *Connection) ReadPump() {
    defer c.ws.Close()
    for {
        _, msg, err := c.ws.ReadMessage()
        if err != nil { return }
        var f Fram
        if err := json.Unmarshal(msg, &f); err != nil { continue }
        switch f.Type {
        case "catch_up":
            c.handleCatchUp(f.LastSeq)
        case "pong":
            c.Heartbeat(pong)
        }
    }
}

func (c *Connection) WritePump() {
    ticker := time.NewTicker(10 * time.Second)
    defer func() {
        ticker.Stop()
        c.ws.Close()
    }()
    for {
        select {
        case frame, ok := <-c.Send:
            if !ok { return }
            c.ws.SetWriteDeadline(time.Now().Add(10 * time.Second))
            if err := c.ws.WriteMessage(websocket.TextMessage, frame); err != nil { return }
        case <-ticker.C:
            // heartbeat
            c.Send <- []byte(`{"type":"heartbeat","ts":"...","seq":N}`)
        }
    }
}

// services/ws-gateway/internal/ws/upgrade.go
func (s *Server) HandleWS(w http.ResponseWriter, r *http.Request) {
    token := r.URL.Query().Get("token")
    if token == "" {
        http.Error(w, "missing token", 401)
        return
    }
    streamerID, err := s.validateToken(r.Context(), token)
    if err != nil {
        http.Error(w, "invalid token", 401)
        return
    }

    conn, err := upgrader.Upgrade(w, r, nil)
    if err != nil { return }

    c := newConnection(conn, streamerID, s.hubs.GetOrCreate(streamerID), s.log)
    c.Hub.AddConnection(c)

    go c.WritePump()
    c.ReadPump()  // blocks until disconnect
    c.Hub.RemoveConnection(c)
}

// services/ws-gateway/internal/subscriber/nats.go
func (s *NatsSubscriber) SubscribeDonations() {
    s.nats.Subscribe("donation.charged.v1.>", func(msg *nats.Msg) {
        var env events.Envelope
        if err := json.Unmarshal(msg.Data, &env); err != nil { return }
        hub := s.hubs.GetOrCreate(env.StreamerID)
        seq := hub.NextSeq()
        frame := DonationFrame{
            Type: "donation",
            Seq: seq,
            StreamerID: env.StreamerID,
            Ts: env.OccurredAt,
            Data: env.Payload,
        }
        data, _ := json.Marshal(frame)
        hub.Broadcast(data)
    })
}
```

## 12. Testing strategy (applies to all phases)

### 12.1 Test pyramid

```
        E2E smoke test (1-2 tests)
       Integration tests (per service, ~10-20 tests)
      Unit tests (per function, hundreds)
```

### 12.2 Test layers per service

**Unit tests** (per function):
- Pure functions: input → output
- Mock all dependencies (DB, NATS, gRPC clients)
- Fast (< 100ms per test)
- Coverage: 80%+

**Integration tests** (per service):
- Real DB (testcontainers: ephemeral Postgres per test)
- Real NATS (in-process or testcontainer)
- Mock external (Midtrans HTTP, gRPC clients to other services)
- Coverage: 80%+

**E2E smoke test** (Phase 9):
- Real Midtrans sandbox
- All services running
- Assert: donation → ledger → event → WS frame in OBS

### 12.3 Test utilities

- `db.go` — ephemeral Postgres setup
- `nats.go` — in-process NATS for tests
